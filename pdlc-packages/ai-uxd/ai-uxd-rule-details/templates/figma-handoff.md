## Component Mapping

The component inventory (Stage 9) maps to Figma component + variant structure — component name → Figma component; state/variant axes → Figma variant properties. Names and axes round-trip; visual composition stays in Figma.

## Round-Trip (Back and Forth)

- **Forward (publish):** UXD → `integrations/figma/out/` → Figma. Always available.
- **Reverse (reconcile):** a Figma export dropped in `integrations/figma/in/` is treated as an **input** (not drift) — invoke `UXC__ sync-figma` to run a governed 3-way diff that proposes changes; a human approves; accepted changes re-emit the canonical. See `PLAN.md` §7.1 for the full extension design.
