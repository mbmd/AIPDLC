# Intake Analysis

## Project Summary

| Field | Value |
|-------|-------|
| **Project Name** | Platform Modernisation Initiative |
| **Requestor** | VP Engineering |
| **Date Submitted** | 2026-04-28 |
| **Priority** | High |

## Problem Statement

The current service platform is a legacy monolith with poor scalability, limited automation, and fragmented user experience. Tier-1 agents spend 35% of time context-switching between systems.

## Business Drivers

- Reduce Tier-1 request resolution time by 60%
- Improve SLA compliance from 78% to 95%
- Enable proactive incident management
- Consolidate fragmented tools into one platform

## Stakeholders Identified

- VP Engineering (Sponsor)
- Head of Operations (Champion)
- CISO (Security oversight)
- Tier-1 Support Team (End users)
- External integration vendor (Integration partner)

## Initial Scope Boundaries

**In Scope:**
- Core request engine
- Self-service portal
- SLA monitoring
- Integration with configuration management database

**Out of Scope:**
- Mobile app (deferred to Phase 2)
- AI chatbot (requires separate evaluation)
- Legacy data archival

Proceed to Requirements Analysis. Strong business case, clear stakeholder alignment, and well-defined problem space.
